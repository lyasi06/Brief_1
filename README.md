## Élan Fitness — Site Multipage

## Introduction

Élan Fitness est une salle de sport. Avant, son site était un one pager.

Le but de ce projet était de transformer ce site en site multipage plusieurs pages séparées. Comme ça, le visiteur trouve plus facilement ce qu'il cherche, et le site est plus professionnel.

## Objectifs du projet

- Passer d'un site one pager à un site multipage
- Créer 4 pages: Accueil, Programmes, A propos, Contactez-nous
- Relier toutes les pages entre elles avec un menu
- Rendre le site responsive
- Améliorer l'expérience du visiteur UX / UI
- Améliorer le référencement SEO
- Utiliser Git pour sauvegarder et suivre le projet

## Outils et technologies utilisés

HTML5: Créer la structure des pages
CSS3: Mettre en forme et styliser le site
Git: Sauvegarder les versions du projet
UX / UI: Améliorer l'expérience et le design
SEO: Aider Google à trouver le site
Responsive: DesignAdapter le site à tous les écrans

## Contenu des pages

###  Accueil
Page qui présente la salle de sport. Elle donne envie au visiteur de découvrir les programmes.

### Programmes
Page qui montre les cours et les formules proposées. Le visiteur peut choisir celle qui lui convient.

###  A propos
Page qui raconte l'histoire de la salle, ses valeurs et présente l'équipe.

###  Contactez-nous
Page avec un formulaire de message, les coordonnées de la salle et un plan d'accès.
